# Alpine Resort Tycoon

Baue dein eigenes Skigebiet im Comicstil: Lifte, Pisten, Hotels, Gäste – und Flocki hilft dir dabei.

**Spielen:** https://kph2pw5bfd-art.github.io/alpine-resort-tycoon/

## Aufs Handy holen

**iPhone (Safari):** Seite öffnen → Teilen-Knopf (Quadrat mit Pfeil) → „Zum Home-Bildschirm“ → „Hinzufügen“.

**Android (Chrome):** Seite öffnen → Menü (⋮) → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

Danach startet das Spiel wie eine App im Vollbild und läuft auch ohne Internet. Mit Internet holt es sich neue Versionen von selbst.

## Spielstand

Der Spielstand bleibt auf dem jeweiligen Handy gespeichert. Zur Sicherung im Hauptmenü „💾 Spielstand sichern“ antippen (Datei), mit „📂 Spielstand laden“ kommt er wieder zurück – auch auf ein anderes Handy.
